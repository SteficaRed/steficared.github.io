Machine Learning Algorithms from Scratch

This project presents the development and explanation of four machine learning algorithms: Naive Bayes, Linear Regression, KMeans and AdaBoost. Each algorithm is implemented in several versions, starting from a simple baseline implementation and gradually improving the code structure, evaluation and interpretation.

Algorithms: Naive Bayes, Linear Regression, KMeans, AdaBoost

Tools: Python, NumPy, Pandas, Matplotlib, Scikit-learn
